# python-scripts
Contain python scripts that automate pdf merging and web scraping , bulk image resizing, testing math and a to-do list application

1. Command-Line To-Do List Manager
Description: A simple CLI-based task management system that allows users to add, list, and remove tasks. The to-do list is saved in a text file, ensuring task persistence between sessions.

2. Bulk Image Resizer
Description: A Python script that automatically resizes all images in a specified folder using the Pillow library. It resizes images to a standard dimension, optimizing them for web uploads or storage efficiency.

3. Automated PDF Merger
Description: This script merges multiple PDF documents into a single file. It processes all PDFs in a given folder, sorts them alphabetically, and combines them into one cohesive document, saving time in document management.

4. Automated Web Scraper for News Headlines
Description: A Python web scraper that extracts the latest news headlines from a website using BeautifulSoup. The headlines are stored in a text file, making it easy to stay updated with current events.

5. Unit Testing Framework for a Math Utility Library
Description: This project demonstrates unit testing in Python by implementing a simple math utility library and testing its functions using the unittest module. It ensures code reliability and correctness through automated testing.
